# Maze Escape v1.4.0 Release Candidate

状态：功能分支发布候选，尚未合并或公开发布。

## 玩家可见变化

- 玩家默认手持长刀，同时携带栓动狙击枪，可使用 `1 / 2`、鼠标滚轮或移动端按钮切换，不再经过武器选择页。
- 狙击枪为高伤害单发武器，使用 5 发弹匣和 20 发备用弹药；每枪后必须拉栓，空弹不会自动换弹，必须按 `R` 或移动端换弹键。
- 鼠标右键或移动端配镜键进入 24 度 FOV 配镜视角；每次刚开镜的前 3 秒使用 0.5 倍时间流速，随后保持配镜但恢复正常速度。
- 第一人称眼位移回角色碰撞胶囊内部并使用 0.03 近裁剪面，修复贴墙时视野穿墙。
- 狙击枪与长刀使用双手支撑姿态，未使用的武器显示在角色背部。
- 换弹期间允许移动和转向，切换长刀会中断换弹并保留当前弹药状态。
- 新增双武器槽 HUD、弹匣与备用弹药、换弹进度、空仓提示、长刀冷却和武器专属准星。
- 僵尸视觉受距离、视野角、墙体遮挡、环境光和局部雾区影响。
- 枪声、长刀攻击和冲刺脚步声使用不同传播半径；僵尸会前往声音位置调查。
- 僵尸失去视野后搜索最后已知位置，附近僵尸只接收有半径和冷却限制的可疑位置警报。
- 删除短局内连续昼夜循环，十关改用供电、低照明、应急红灯、断电、污染、封锁和地下深层等固定环境状态。
- 局部雾区同时使用空间粒子、HUD 后层雾幕和状态提示，并降低区域内僵尸视野。

## 工程改造

- `WeaponController` 把已拥有武器、当前武器、弹匣、备用弹药和瞬时动作分开管理。
- `EnemyPerception` 负责视觉、听觉和目标记忆。
- `EnemyDecisionModel` 使用可独立测试的 Utility 分数选择巡逻、调查、搜索、追击或攻击。
- `EnemyAgent` 保留已有网格 A*、移动、攻击、动画和对象池执行职责。
- `NoiseSystem` 统一广播枪声、刀声、脚步声和有限群体警报。
- `LevelDefinition` 用 `DungeonCondition` 和局部雾区数量替代短局昼夜参数。
