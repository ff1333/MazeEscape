# Fogbound Maze v1.3.0

发布日期：2026-10-05。

## 主要更新

- 默认简体中文，支持英文切换。
- 主菜单新增静音、总音量、音乐和音效音量，选择保存在本机。
- 关卡图鉴、武器选择和动态 HUD 使用中英文本地化与中文字体。
- 保留十关不同迷宫、顺序解锁、第一/第三人称、小地图、A* 僵尸、冲锋枪、长刀、装弹反馈、昼夜、浓雾、瘴气和全图避难灯。
