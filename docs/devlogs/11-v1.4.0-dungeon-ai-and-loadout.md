# v1.4.0 地下城战斗与感知 AI 开发记录

日期：`2026-10-28`

## 一、需求来源

试玩反馈指出：全局雾表现不明显；开局二选一使枪声与刀声无法形成持续选择；空弹自动换弹缺少控制感；HUD 不能同时表达枪和刀；短局昼夜循环没有足够决策意义；敌人主要按距离追击，存在隔墙感知和全知目标问题。

本轮将这些问题统一成一个目标：把游戏从“带环境效果的迷宫”收敛为“使用双武器控制噪声风险的地下城撤离”。

## 三、双武器与手动换弹

`GameInput` 新增枪、刀切换输入；`PlayerController` 在攻击前处理武器切换。后续试玩将原冲锋枪收敛为栓动狙击枪：`WeaponController.PrepareLoadout()` 在关卡加载时初始化 5 发弹匣和 20 发备用弹药，并默认手持长刀；`Equip()` 只切换当前武器，因此切换不会凭空补充弹药。

换弹流程：

```text
R / 移动端换弹
→ 当前为狙击枪
→ 弹匣未满且备用弹药大于 0
→ 进入 Reload 协程
→ 完成后只转移实际缺少的弹药
```

空弹攻击只触发空仓音效与提示，不启动换弹。切刀会停止换弹协程，但不会回滚或补充弹药。

## 四、武器 HUD

HUD 右下角始终显示狙击枪和长刀槽位，当前武器高亮。狙击枪显示弹匣、备用弹药、拉栓进度、换弹进度、专注时间和空仓提示；长刀显示攻击距离与恢复时间。普通枪械视角使用四向准星，配镜时改为圆形遮罩和十字线，长刀使用横向近战范围提示。

准备界面不再二选一。关卡加载后默认手持长刀并直接开放入口，玩家进入后可以随时切换狙击枪。

## 五、敌人感知、记忆和决策

视觉判断依次检查：有效视距、水平视野角和墙体 Linecast。环境状态和局部雾区共同缩放有效视距。

`NoiseSystem` 传播：

- 狙击枪：42 米；
- 长刀：7 米；
- 冲刺脚步：10 米，按时间间隔发出；
- 僵尸警报：普通 12 米、精英 16 米，并有 4 秒冷却。

声音和警报只提供发生位置。敌人不会因此持续获得玩家实时坐标。

Utility AI 的意图优先级由分数决定：直接攻击高于追击，追击高于声音调查，调查完成后搜索最后已知位置，记忆过期后回到巡逻。A*、移动、攻击和动画仍由 `EnemyAgent` 执行。

## 六、地下城环境

删除运行时太阳循环，改为每关固定 `DungeonCondition`。固定规则更适合数分钟关卡，也让失败原因更容易理解。

局部雾区由关卡种子确定，避开入口和出口。进入雾区后：

- 状态栏显示“局部浓雾”；
- HUD 后层显示平滑雾幕，不遮挡操作信息；
- 世界粒子保留空间位置提示；
- 玩家观察变差，敌人有效视距同步乘以 `0.55`。

## 八、已知边界

- 当前 Utility 分数是可解释规则，不是机器学习模型。
- 局部雾粒子在部分 URP 设备上的可见度可能不同，因此 HUD 雾幕承担可靠反馈。
- 备用弹药暂未加入场景拾取补给；弹药耗尽后需要使用长刀完成关卡。
- 真人战斗手感、Android 真机和最终难度仍需作者验收。

## 九、贴墙相机、栓动狙击枪与双手持械补充

本轮根据 Windows 实际试玩继续处理三个直接影响手感的问题：第一人称眼位原先向前偏移 0.5 米，角色碰撞体尚未碰墙时相机可能先穿过墙；冲锋枪与长刀的风险差异不足；角色手持和背负状态不够明确。

- 第一人称眼位改为角色胶囊内部仅前移 0.04 米，近裁剪面改为 0.03，第三人称继续使用 SphereCast 避墙。
- 冲锋枪替换为高伤害栓动狙击枪：80 米射程、100 伤害、5 发弹匣、20 发备弹、每枪 0.85 秒拉栓、2.2 秒手动换弹。
- 右键或移动端 `SCOPE` 按住配镜；每次新开镜前 3 秒为 0.5 倍时间流速，3 秒后继续保持配镜但恢复正常速度。
- 拉栓期间禁止再次开火或换弹，HUD 显示拉栓进度，程序化机械声和第三人称动作共同反馈上膛过程。
- 使用角色现有骨骼和运行时支撑手 IK 表现双手持枪/持刀；当前武器手持，另一把武器挂在背部。
- Blender 5.2.3 LTS 已安装到 E 盘，供后续需要手工关键帧时使用；本次基础动作没有把外部现成动画冒充为自行制作。
