# v1.4.0 分层局部雾效收尾

日期：2026-10-31

## 1. 试玩反馈

旧版局部雾使用单层大尺寸 Billboard 和 Box 发射区域。虽然能表达雾区位置，但近看像规则雾团，方形边缘明显，屏幕雾幕也偏重。

## 2. 实现

- 每个雾区拆成贴地雾、漂移雾和少量尘埃三层；
- 使用 Sphere 发射区域和 Shape 缩放形成不同高度层次；
- 启用低质量 Noise，提供缓慢卷动而不增加过高移动端成本；
- 运行时生成 `64 x 64` 柔边噪声纹理，消除方形粒子边缘；
- 使用生命周期透明度曲线淡入淡出；
- 每个雾区粒子上限为 `128`；
- HUD 雾幕改为平滑过渡并降低不透明度；
- 保留雾区半径和敌人 `0.55` 视距倍率，未修改玩法难度规则。

## 4. 面试说明

雾区的逻辑半径与视觉粒子分离：`MazeWorld` 继续负责是否进入雾区和敌人视距修正，三层粒子只负责表现。这样可以单独迭代美术效果，而不会改变敌人感知和关卡难度。测试同时限定粒子层数和预算，防止视觉优化造成移动端性能回归。
