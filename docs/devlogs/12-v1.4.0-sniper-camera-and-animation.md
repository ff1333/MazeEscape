# v1.4.0 栓动狙击枪、贴墙相机与持械表现开发记录

日期：`2026-10-28`

## 一、试玩问题

1. 第一人称贴近墙面时，相机可能先于角色碰撞体穿过墙。
2. 开局武器选择没有必要，玩家希望默认长刀并在局内切枪。
3. 原冲锋枪连续输出过强，缺少换弹和单发节奏。
4. 武器看起来主要由单手持握，未使用武器也没有明确去向。

## 二、实现

- 第一人称眼位从向前 `0.5m` 改为胶囊内部向前 `0.04m`，近裁剪面改为 `0.03`。
- 开局调用 `PrepareLoadout()` 后默认装备长刀并直接确认入口，不再显示武器选择页。
- 冲锋枪替换为栓动狙击枪：100 伤害、80 米射程、5 发弹匣、20 发备用弹药。
- 狙击枪只响应单次按下；每枪后进入 `0.85s` 拉栓，期间不能射击或换弹。
- `R` 手动换弹，时长 `2.2s`；空仓不会自动装填。
- 鼠标右键和移动端 `SCOPE` 按住配镜，FOV 为 24；每次新开镜前三秒使用 `Time.timeScale = 0.5`，之后恢复 1。
- HUD 新增圆形配镜遮罩、十字线、拉栓进度、换弹进度和专注剩余时间。
- 当前武器手持，另一把武器挂在 `Torso`；运行时支撑手 IK 把另一只手贴到枪身前护木或刀柄。
- 拉栓使用机械音、HUD 状态、第一人称武器位移和第三人称 `Idle_Attack` 动作共同反馈。

- 狙击枪伤害、42 米噪声和 5+20 弹药是否适合十关整体难度。

- Android 触控配镜、切枪和换弹是否顺手。
- 长刀与狙击枪的双手姿态在所有移动、攻击和受伤角度下是否需要 Blender 继续精修。
